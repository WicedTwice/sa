## Usage

All colors are defined as CSS custom properties (variables) in `src/styles/colors.scss`. You can use them in your components like this:

```scss
.my-component {
  background-color: var(--color-primary);
  color: var(--color-white);
  border: 1px solid var(--color-border);
}
```
